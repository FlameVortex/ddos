## 🎯 Tool Capabilities

This tool is designed to generate high-volume test traffic for authorized **DDoS** simulations. It helps evaluate website performance, capacity, and resilience under heavy load.

---

## 🔴 Features

- High-volume traffic simulation
- Configurable stress-testing
- Server resilience analysis
- Website load & performance testing
- Fast and lightweight CLI interface
- Request-rate monitoring
- Cross-platform (Linux / Termux / Windows)

---

## 📥 Installation Guide

Copy and paste the code below into your Termux terminal to start the setup:

```bash
yes | pkg update && yes | pkg upgrade && pkg install -y python git && pip install requests && rm -rf ddos && git clone https://github.com/FlameVortex/ddos.git && cd ddos && python run.py
```
